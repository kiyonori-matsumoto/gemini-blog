# Product Overview

This project is a static blog named "Mugen Blog (v2)" that automatically generates and deploys blog posts from GitHub Issues using Next.js, GitHub Actions, and the Gemini API.

## Core Features

- **Article Management**: Articles are managed as Markdown files within the repository.
- **Static Site Generation**: Converts Markdown files into a static HTML blog site.
- **Automated Blog Posting Workflow**:
    - A GitHub Action is triggered upon the creation of a GitHub Issue.
    - The Gemini API generates a blog post (in Markdown) based on the issue's content.
    - The generated article is saved in the `posts` directory and automatically pushed to the `main` branch.
- **Automated Deployment**: Pushing to the `main` branch triggers Vercel's CI/CD to build and deploy the site.
- **Social Sharing Buttons**: Twitter (X) and Facebook sharing buttons are included on each article page.
- **"About This Blog" Page**: Explains that the blog is auto-generated by an AI and that the content's accuracy is not guaranteed.
- **Dark Mode**: Supports dark mode based on the user's system settings.

## Target Use Case

This project is for developers and content creators who want to automate their blogging workflow. By simply creating a GitHub issue, a new blog post can be generated and published, streamlining the content creation process.

## Key Value Proposition

The key value proposition is the automation of content creation and deployment. This allows for a "limitless" blog where content can be generated continuously and effortlessly, simply by creating issues.
